# Packaging and deployment

- **Desktop JAR:** `gradlew :games:sandbox:dist` (same as `:redshell-desktop:jar`), output in `redshell-desktop/build/libs`.
  Run with `java -jar <file>.jar` (needs a JDK/JRE 17+).
- **Browser:** `gradlew :redshell-html:dist`, then serve `redshell-html/build/dist` from any static web server
  (opening the files directly will not work).
- **Assets:** everything in `assets/` is bundled; `assets.txt` is regenerated by the build.
- **CI:** `.github/workflows/build.yml` runs build, tests, asset validation, the GWT compile and the desktop JAR.
- A native bundle (no JRE required, e.g. with Construo) is not set up yet.
